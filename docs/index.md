# Исследование генераторов статических сайтов

Добро пожаловать на исследовательский сайт, посвящённый
публикации результатов вычислительных экспериментов.

## О проекте

Сайт разработан в рамках лабораторной работы
по веб-технологиям Университета ИТМО.

В рамках исследования рассматриваются:

- MkDocs с темой Material;
- Sphinx с MyST-Parser;
- Pelican;
- Quarto.

## Цели исследования

1. Сравнить возможности генераторов статических сайтов.
2. Исследовать способы публикации научного контента.
3. Автоматизировать сборку и развёртывание сайта.
4. Реализовать воспроизводимый конвейер обработки данных.
